Bulk upload validations:



File Validation:

Only .xlsx files are allowed.
File must be readable and follow the approved template.
Required columns must be present.
Duplicate column names are not allowed.
File must contain at least one data row.
Blank rows are ignored.

Network Hierarchy Validation
Zone must exist.
Sub Station must exist and belong to the selected Zone.
Feeder must exist and belong to the selected Sub Station .
DTR must exist and belong to selected Feeder.


Meter Bulk Upload Validations

1. Meter Identification Validation
Meter Serial Number is mandatory.
Asset ID and RAPDRP Code should match Meter Serial Number or remain blank.
Meter Serial Number must be unique.
Duplicate Meter Serial Numbers within the upload file are not allowed.
Existing meters cannot be uploaded again.

2. Meter Master Validation
Meter Manufacturer must exist.
Meter Model must exist if provided.
Meter Status must contain valid values.
DLMS / Non-DLMS must contain valid values.

3. Meter Configuration Validation
MPTR, MCTR, LPTR, and LCTR must be valid integers.
MF must be greater than zero.
Display Digit must be a valid positive integer.

4. Date Validation
Meter PO Date must be valid.
Meter Testing Date must be valid.
Future dates are not allowed.
Testing Date must be greater than or equal to PO Date.

5. Field Length Validation
Accuracy Class maximum 8 characters.
Meter PO Number maximum 32 characters.
Meter Version maximum 32 characters.
Meter Rating maximum 15 characters.


DTR Bulk Upload Validations:

1. DTR Validation
DTR Code is mandatory and unique.
DTR Name is mandatory.
DTR Capacity must be greater than zero.
Status must contain valid values.
Duplicate DTR Codes within the upload file are not allowed.

2. Meter Mapping Validation
Meter Serial Number is mandatory.
Meter must exist.
Meter must be active.
Meter must not already be mapped to another DTR.
Main/Sub Meter must contain valid values.
Meter Phase must contain valid values.
Service Point ID is mandatory.

3. Communication Validation
SIM Number is mandatory.
IMSI Number must contain digits only.
IP Address must be valid.
Modem Serial Number is mandatory.
Modem IMEI must contain 15 digits.

4. Date Validation:
Service Date and Installation Date must be valid.
Future dates are not allowed.


Consumer Bulk Validations:

1.Consumer Validation
Consumer ID is mandatory and unique.
Nearest Account ID must be valid.


2.Connection Validation
Billing Cycle must be valid.
Bill Day must be between 1 and 28.
Consumer Category must be valid.
Connection Type, Status, and TOD must be valid if provided.

3.Meter Validation
Main/Sub Meter must be valid.
Meter Serial Number (MSN) is mandatory.
Meter must be active.
Meter must not already be mapped.
Service Point ID is mandatory.
Meter Phase must be valid.
Meter Initial Reading must be greater than 0.

4.Communication Validation
SIM Number is mandatory.
IMSI Number must be numeric.
Meter Mobile Number must contain 10 digits.
IP Address must be valid.
Modem Serial Number is mandatory.


5.Duplicate Validation
Consumer ID must be unique.
Meter Serial Number must be unique.
